# 広東語

広東語（香港の話し言葉の書き方。繁体字）の文を語に切り分け、広東語の語を普通話の語に置き換えて並べ替えてから
（佢 → 他、嘅 → 的、咗 → 了、我高過佢 → 我比他高）、中国語（普通話）の解析器（`chinese/`。spaCy の品詞・依存関係、
量詞・的・アスペクト・把・被 …）で日本語に訳します。表示は広東語の字のまま、見出しの行に粤拼（Jyutping）を添えます。

```
./dragoman.py yue -e "你食咗飯未呀？"
  你食咗飯未呀？  (nei5 sik6 zo2 faan6 mei6 aa4?)
  →  あなたが / {飯,食事}を / 食べたか
./dragoman.py yue -e "佢係我嘅朋友。"          →  彼は / 私の友人である
./dragoman.py yue -e "佢畀本書我。"            →  彼が / 私に / 本を / 与える
./dragoman.py yue -e "我唔知佢喺邊度。"        →  私が / {彼が どこ いる,ある}かを / 知らない
./dragoman.py yue -e "佢哋同我一齊去飲茶。"    →  彼らが / 私と / お茶を / 一緒に / 飲みに行く
./dragoman.py yue -k -e "唔該。"               カナ: ム ゴイ
python3 tools/samples.py --lang=yue            # サンプル (samples/cantonese.txt) の訳
```

かなの無い漢字の文で、広東語らしい字（佢・嘅・咗・唔・冇・喺・嘢・哋・啲・嗰・睇 …）か語（而家・點解・邊度・鍾意 …）が
あれば広東語と推定します（無ければ普通話、助字の多いものは漢文）。

  （約10万語）。英語の語義と「Mandarin equivalent: 看」の普通話の語

## 語の切り分け（`cantonese/segment.py`）

PyCantonese の切り分けを基本に、辞書（広東語の表・CC-Canto・CC-CEDICT）に無い2字以上の語（畀本書・高過）は見出しの
最長一致で分け直します。否定・存在の語で始まる語（唔係・冇錢）、動詞 + 目的語（睇戲・食飯）、反復疑問（係咪・有冇）も
分けます。指示詞・数詞の後ろの「量詞 + 名詞」（呢本書）は量詞の前で切ります。

## 普通話への置き換え（`cantonese/morphology.py`）

* 語の表（MANDARIN）: 代名詞（佢 → 他、我哋 → 我们）、指示詞・疑問詞（嗰 → 那、邊度 → 哪里、乜嘢 → 什么、點解 → 为什么）、
  係 → 是、喺 → 在、冇 → 没有、唔 → 不、嘅 → 的、啲 → 一些、アスペクト（咗 → 了、緊 → 在、過 → 过）、よく使う動詞・名詞・
  形容詞（食 → 吃、睇 → 看、講 → 说、鍾意 → 喜欢、嘢 → 东西、屋企 → 家、靚 → 漂亮、攰 → 累）、都 → 也（広東語の 都 は「〜も」）
* 表に無い語は簡体字に（OpenCC）。CC-CEDICT に無い語は CC-Canto の普通話の語か英語の語義で訳す
* 好 + 形容詞・心の動詞は 很（好靚「とてもきれい」）、幾 + 形容詞は 挺。文末の 呢 は語気、ほかの 呢 は指示詞「この」
* 並べ替え: 比較（形容詞 + 過 + 名詞 → 比 + 名詞 + 形容詞）、二重目的語（畀 + 物 + 人 → 给 + 人 + 物）、受動（畀 + 人 + 動詞 →
  被）、進行（動詞 + 緊 → 在 + 動詞）、動詞 + 先 → 先 + 動詞、反復疑問（去唔去・係咪・有冇・得唔得閒 → 文末に 吗）、
  文末の 未・咩 → 吗、数詞・指示詞の無い 量詞 + 名詞（本書「その本」）は名詞1つに
* 文末の助詞（喇・啦・㗎・喎・啩・囉 …）は訳さない
* 同 + 人 + 動詞は 跟（「〜と」）

## カタカナ読み（`cantonese/katakana.py`）

`--kana` は粤拼（PyCantonese）から音節ごとに。声調と母音の長さは書きません: 你好 → ネイ ホウ、唔該 → ム ゴイ、
香港 → ヒョン ゴン、廣東話 → グォン ドン ワ、飲茶 → ヤム チャ。

* 無気音 b・d・g・z はバ・ダ・ガ・ジャ行、有気音 p・t・k・c はパ・タ・カ・チャ行（普通話のカタカナと同じ）
* gw・kw はグァ・クァ行、ng はガ行、j はヤ行。yu はユ段（書 → シュ）、oe は拗音（香 → ヒョン）、eo はオ（佢 → コイ）
* 末子音 -m ム、-n・-ng ン、-p ップ、-t ット、-k ック。u + ng・k はオン・オック（東 → ドン、六 → ロック）
* 音節だけの m（唔）はム、ng（五）はン

## 音読（`-s`）

macOS の say の Sinji（香港）、無ければ espeak-ng（yue）。

## まだできないこと

* 係り受けは普通話のモデル（zh_core_web_sm）を置き換えた語に掛けたもの。広東語の語順のままの文（句末の補語、文末の助詞の
  組み合わせ）は外れやすい。UD Cantonese-HK での評価はまだ（ツリーバンクの取得が要る）
* 「〜より」「先に」などの副詞が主語より前に出る（彼より / 私は / 高い）
* 文末の助詞のニュアンス（喇「〜した（変化）」・㗎・喎・啩）と、文末の 未 の「もう」は訳さない
* 解析の表の見出しの読みは普通話の拼音（語の置き換え先）。粤拼は見出しの行とカナに
* 書き言葉の広東語と普通話の混ざった文（香港の新聞の文）、英語の混ざった文（code-mixing）
