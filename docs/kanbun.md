# 漢文（作りかけ）

漢文（白文）に返り点を付け、書き下し文（送り仮名は歴史的仮名遣い）と現代語訳を作ります。言語の符号は `lzh`
（ISO 639-3 の文言）。`kanbun` でも呼べます。かなの無い漢字の文で、助字（之・乎・也・矣・曰・吾・勿・豈 …）があり、
現代中国語の字（的・了・吗 …）の無いものは、言語を指定しなくても漢文として読みます。

```
pip install udkanbun                    # UD-Kanbun (安岡孝一、MIT。約 20 MB)
mkdir -p ~/.local/share/dragoman-data/kanjidic && cd ~/.local/share/dragoman-data/kanjidic
curl -O http://www.edrdg.org/kanjidic/kanjidic2.xml.gz       # KANJIDIC2 (EDRDG、CC BY-SA 4.0。約 1.5 MB)
cd - && ./dragoman.py kanbun -e "學而時習之、不亦說乎。"
```

```
學而時習之、不亦說乎。
  返り点   學而時習㆑之、不㆓亦說㆒乎。
  書き下し 學びて時に之を習ふ、亦た說ばしからずや。
  読み     まなびてときにこれをならふ、またよろこばしからずや。

  學  動詞・行為  述語  study「勉強する」  → 學びて
  而  助詞・接続  接続  and  (読まない)  置き字 (読まない。前の用言を「〜て」(順接)・「〜ども」(逆接) でつなぐ)
  時  名詞・時  補語  time「時間」  → 時に
  …
  →  学んで時々これを習う、またうれしいではないか。
```

主語の「は」は、教科書に合わせて書き下しには付けません（春眠曉を覺えず・青藍より出でて藍より青し。「者」の後ろは
付ける: 知者は）。`--wa` で付けます（春眠は曉を覺えず）。現代語訳にはいつも付けます。

ノート（`--html=FILE`・`--pdf=FILE`）では、白文を縦書きにして訓点を付けます（`dragoman/kanbun/note.py`）。
振り仮名（ひらがな）は字の右、送り仮名（カタカナ）はその下、返り点は左下、再読文字の二度目の読みの送り仮名は左（將ニ…ス）。置き字 於 から来る
「に・より」は前の名詞の送り仮名に、字を仮名で読む助字（不・可・使）は活用の部分だけを（不ル・可カラ・使ム）付けます。

字の読み（振り仮名と「読み」の行。`dragoman/kanbun/ruby.py`）:

* 助字・副詞・代名詞: 手作りの表（歴史的仮名遣い: 則 すなは・焉 いづ・汝 なんぢ）
* 用言: KANJIDIC2 の訓のうち、送り仮名の行が合うものの語幹（學び → まな、出でて → い、欲せ → ほつ は表）
* 名詞・熟語: JMdict の表記と読み。字ごとの音・訓に分けられる読みのうち（虎子 こし。まる でなく）、語義が
  UD-Kanbun の Gloss に合うもの（生 せい・子 し）、1字なら訓を先に（人 ひと）。書き下しで続く名詞は熟語として引く
  （遠方・虎穴）
* 用言・名詞の読み（KANJIDIC2・JMdict は現代仮名遣い）は歴史的仮名遣いに直します（王 わう・遠方 ゑんぱう・青 あを・
  春眠 しゆんみん）。英語版 Wiktionary の日本語の語の見出しの振り仮名と歴史的仮名遣いから、字ごとの対応の表を作って
  使います（語の表に無ければ字の表で。どちらにも無ければ現代仮名遣いのまま）

JMdict の読みの表は `python3 tools/build_ja_readings.py` で作ります（`$DRAGOMAN_DATA/ja-readings.tsv`。
JMdict_e.gz から。無ければ読みは出しません）。歴史的仮名遣いの表は `python3 tools/build_ja_historical.py` で
（`$DRAGOMAN_DATA/ja/historical-kana.tsv`。kaikki の英語版 Wiktionary の日本語 `ja/kaikki.org-dictionary-Japanese.jsonl`、
約 390 MB、CC BY-SA から）。

* 語の切り分け・品詞・係り受け: [UD-Kanbun](https://github.com/KoichiYasuoka/UD-Kanbun)（MeCab + UDPipe。
  京都大学人文科学研究所の漢文の UD ツリーバンクで学習したもの）。英語の語義（Gloss）もここから。よくある係り受けの
  誤りは `parse.repair` で直し（名詞の主語を述語と読んだもの: 百聞不如一見 → 百聞一見に如かず・春眠不覺曉 → 春眠
  曉を覺えず。二つの節の主語を前の動詞の目的語と読んだもの: 國破山河在 → 國破れて山河在り。1字の名詞の並び（山河）は
  熟語に）、返り点は直した係り受けから UD-Kanbun の規則で付けます。
* 読む順序（`dragoman/kanbun/kundoku.py`）: 語ごとに、係り先より前の語（主語・副詞・連体修飾）はそのまま前に、
  後ろの目的語・補語・前置詞句（obj・iobj・obl・ccomp・xcomp）は係り先の前に移し、否定・助動詞・前置詞などの助字
  （不・可・欲・所・於 …）は係り先の後ろに回します。並列・続く節・文末の助字はそのまま後ろ。
* 送り仮名: 後ろの語が前の用言に求める活用形を右から左へ決めます（ず → 未然形、べし → 終止形（ラ変・形容詞は連体形）、
  所・者・を → 連体形、而 → 連用形 + て、則 → 已然形 + ば）。形容詞は助動詞の前でカリ活用（樂しからず）。
* 句法: 置き字（而・於・矣・焉・兮）、再読文字（未だ〜ず・將に〜んとす・當に〜べし・宜しく〜べし・須らく〜べし・
  猶ほ〜ごとし・盍ぞ〜ざる）、使役（AをしてBせしむ）、受身（見る・被る → る / らる）、禁止（勿かれ）、否定（非ず・莫し・
  如かず）、不可（べからず）、反語・疑問（焉くんぞ〜ん・豈に〜ずや）、仮定（不A不B → Aずんば Bず）、比較（於 → より）、
  是謂X（是を X と謂ふ）。助動詞・助詞に当たる字（不・可・使・也・乎・之・與・自 …）はひらがなで書きます。
* 用言の訓（`dragoman/kanbun/readings.py`）: よく出る字は手作りの表（語義で読み分ける: 說 → 說ばし / 說く、
  過 → 過つ / 過ぐ）。無ければ KANJIDIC2 の訓（送り仮名付き）から JMdict の英語の語義が UD-Kanbun の語義に合うものを
  選び、古文の活用の型に直します（`generate/kobun.py` の `classical_verb`）。どれも無ければ音読み + す（サ変）。
* 現代語訳（`dragoman/kanbun/modern.py`）: 書き下しと同じ要素の列から組み立て直します。用言は文語の終止形から現代語の
  見出しに（中古和文UniDic の語彙素。罔し → 暗い）、助動詞は現代語の働きに（ず → ない、べし → ことができる、
  しむ → せる、勿かれ → てはならない、ずや → ではないか、反語 → どうして〜だろうか）。
* 音読（`-s`）は書き下し文（新字体）を macOS の say の日本語音声で。

まだのこと: `parse.repair` の型に当たらない係り受けの誤り（城春草木深 など）はそのまま読みます。抑揚（況んや〜をや）・
累加・限定（唯だ〜のみ）の組、連体修飾の節の「の」と「が」、熟語の読み分け、語ごとのカタカナ読み（`--kana`）は未対応。
