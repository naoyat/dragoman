# モンゴル語（作りかけ）

現代モンゴル語（ハルハ方言・キリル文字）の語を、辞書（Wiktionary の見出しと名詞の変化表）と規則で語幹と接尾辞に分け、
格の接尾辞から格の枠を決めて日本語に訳します。日本語と同じ主語-目的語-動詞の語順で、格の接尾辞が助詞にほぼ対応するので、
韓国語・トルコ語と同じく「語順のまま」の訳（≒）も添えます。

```
./dragoman.py mn -e "Хүү өчигдөр охинд ном өгсөн."
  →  {少年,息子}は / 昨日 / {少女,娘}に / 本を / 与えた
  ≒  少年は 昨日 少女に 本を 与えた。  (語順のまま)
./dragoman.py mn -e "Батын бичсэн захиа ширээн дээр байна."
  ≒  Батが 書いた 手紙は 机の上に ある。  (語順のまま)
python3 tools/samples.py --lang=mn              # サンプル (samples/mongolian.txt) の訳
./dragoman.py mn samples/mongolian.txt             # 解析の詳細 (-w で語ごとの辞書引きを省く)
```

ө・ү のあるキリル文字の文は、言語を省略してもモンゴル語と推定します。ラテン文字の転写（Wiktionary の öčigdör・sajn、
文法書の Xüü öcigdör oxin-d nom ög-sön のようなハイフンで形態素を区切ったもの）もキリル文字に直して読みます。

## 接尾辞と訳

| 接尾辞（母音調和で4通り） | 働き | 訳 |
|---|---|---|
| （無標） | 主格・不定の目的語 | が・は（文の最初の名詞は主題）、動詞の直前は「を」（ном өгсөн「本を与えた」） |
| -ын / -ийн / -ы / -н | 属格（後ろの名詞に掛かる。関係節の主語にも） | の・が |
| -ыг / -ийг / -г | 対格 | を |
| -д / -т（子音の連続の後は -ад / -эд / -од / -өд: хотод） | 与位格 | に・で |
| -аас / -ээс / -оос / -өөс | 奪格 | から |
| -аар / -ээр / -оор / -өөр | 造格 | で |
| -тай / -тэй / -той | 共同格 | と（Заан хоёр том соёотой「象は二本の大きな牙を持つ」） |
| -руу / -рүү | 方向格 | へ |
| -аа / -ээ …（格の後ろ） | 再帰所有 | 自分の |

* 用言: -на（現在・未来）、-лаа・-в・-жээ（過去）、-сан（過去。文末なら定形、名詞の前なら連体）、-даг（習慣）、-х（未来・不定）、
  否定 -гүй、命令・勧誘（-аарай・-я）。動詞は人称で変わらないので、主語を書かなければ補わない。
* 副動詞は節を区切る接続の語: -ж「〜して」、-аад「〜してから」、-вал「〜なら」、-тал「〜するまで」、-хаар「〜しに」、
  -саар「〜しながら」。-ж байна は進行「〜している」。
* 分詞は後ろに名詞があれば関係節（Батын бичсэн захиа「バトが書いた手紙」）、格が付けば名詞化（байхдаа「いる時に」、
  уншихыг「読むことを」）。
* 名詞の述語（Би багш「私は先生だ」）には見えない繋辞を補う（与位格なら存在「ある」、共同格なら所有「〜を持つ」）。бол・нь は主題「は」、биш は否定の繋辞、
  уу・вэ は疑問。
* 語幹: 辞書の名詞の変化表にある形はそこから。無ければ接尾辞を規則で外し、語幹（脱落した母音・н を戻して）が名詞の見出しなら
  名詞、語幹（+ 母音）+ х が動詞の見出しなら動詞（өгсөн → өгөх、амьдардаг → амьдрах）。

## 伝統的なモンゴル文字

文を伝統的なモンゴル文字（ᠮᠣᠩᠭᠣᠯ ᠪᠢᠴᠢᠭ᠌）に書き直します（`dragoman/mongolian/traditional.py`）。端末では見出しの下に
横に並べ、その転写を添えます（* は規則で推定した綴り）。ノート（`--html=FILE`・`--pdf=FILE`）では縦書き（列は左から右へ）に
し、語ごとにキリル文字との対照の表（キリル文字・その転写・モンゴル文字・その転写・出典・主な違い）を付けます。
フォントは Noto Sans Mongolian（macOS に入っているもの）。

```
./dragoman.py mn -e "Хүү өчигдөр охинд ном өгсөн."
  モンゴル文字 ᠬᠥᠪᠡᠭᠦᠨ ᠥᠴᠦᠭᠡᠳᠦᠷ ᠥᠬᠢᠨ ᠳᠦᠷ ᠨᠣᠮ ᠥᠭᠦᠭᠰᠡᠨ
  転写         köbegün öčügedür ökin-dür nom ögügsen
```

伝統文字の綴りはキリル文字と一対一に対応しません（キリル文字は20世紀の発音に合わせた綴り、伝統文字は古い発音を残した綴り）:

* キリル文字で書かない母音を書く（өчигдөр ↔ öčügedür、бичсэн ↔ bičigsen）
* 長母音は母音 + γ / g + 母音（ширээ ↔ sirege、заан ↔ ǰaγan）。語末の n が残るもの（хүү ↔ köbegün）
* 語頭の音節のほかの о・ө は u・ü（өгсөн ↔ ögügsen）。語頭の音節の母音そのものが違うもの（охин ↔ ökin）
* х・г は同じ字 ᠬ・ᠭ を母音調和で q / k・γ / g と読む。ш は s（ᠰ）、ц・з は č・ǰ
* 格の接尾辞は狭い空白（U+202F）で離して書き（ökin-dür）、語末の母音 a・e の前は母音分離記号（U+180E: aq-a）。否定 -гүй は
  別の語 ügei（үзсэнгүй ↔ üǰegsen ügei）

語幹の綴りは、手作りの表（よく使う語・代名詞・後置詞・小辞）→ 辞書（Wiktionary の見出しの伝統文字の綴り。無ければ語源の
Classical Mongolian の綴り）→ 規則での推定（長母音・о / ө・語末の子音の連続に u / ü …）の順に引きます。推定した綴りは
ノートでは灰色、端末では * を付けます。接尾辞（格・再帰所有・複数、動詞の時制・分詞・副動詞）は語幹の母音調和と最後の音で
伝統文字の綴りにします（与位格 -dur / -dür、r・s・d・b・γ・g の後は -tur / -tür、属格は母音の後 -yin・n の後 -u / -ü …）。
転写は q・γ（後舌母音の語）・k・g（前舌母音の語）、ǰ・č・š。

## 準備

```
mkdir -p ~/.local/share/dragoman-data/mn/ud && cd ~/.local/share/dragoman-data/mn
curl -L -O https://kaikki.org/dictionary/Mongolian/kaikki.org-dictionary-Mongolian.jsonl    # 約13MB (CC BY-SA)
cd - && python3 tools/build_mongolian_dic.py      # → ~/.local/share/dragoman-data/mn/wiktionary.sqlite
```

見出し語 5,700・名詞の変化形 1.3 万と小さめなので、基本の語の訳語は `mongolian/morphology.py` の GLOSSES で決めておきます。

評価用に UD Mongolian-GDUD（CC BY-SA 4.0。dev ブランチの test）を `~/.local/share/dragoman-data/mn/ud/` に置きます。

## 評価

```
python3 tools/ud_eval.py --lang=mn
```

GDUD は文法書の例文 88 文で、ラテン文字の転写（流儀が文ごとに混ざり、IPA の ɔ・ə・ʰ も使う）なので、キリル文字に直して
渡します。主語の再現率 73%・目的語の再現率 31%、述語の検出 79%（分詞の節は共通の解析器の関係節に）。目的語の取りこぼしの多くは、IPA 式の転写（nɔm-ig・patʰ-ar）が
キリル文字の標準の綴りに戻らないもの。キリル文字の評価用コーパスがあれば測り直したい。

## 音読（`-s`）

モンゴル語の音声が手元に無いので、espeak-ng のキルギス語の音声（ky。キリル文字の読みが近い）で代用する。

## まだのこと

* 伝統的なモンゴル文字の入力（表示はできた。入力は、ラテン文字に転写して伝統文字の綴りの規則で接尾辞を分け（接尾辞の前の
  U+202F が切れ目）、語は Wiktionary の伝統文字の綴りでキリル文字の見出しに対応させる）。規則での推定の綴りの精度（キリル文字で
  書かない母音の位置は推定できない）。字形の選択の記号（FVS）は付けない。
* 出口（`generate/mongolian.py`）: 4通りの母音調和の格の接尾辞と動詞の語尾、否定 -гүй、分詞の関係節。比較の表にも。
  辞書に無い名前はカタカナ（Бат → バト）、ほかの言語へはラテン文字（Dorzh）。従属節は副動詞に（ирэхэд・ирвэл・иртэл・
  дуулдаг учраас）、同じ主語の et は -аад（Гэр рүү ирээд …）。入口の副動詞の印（-аад・-вал・-тал）は枠の et・sī・dōnec に。
