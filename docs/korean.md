# 韓国語（作りかけ）

韓国語の文を、語節（空白で区切った単位）ごとに形態素解析器 kiwipiepy で内容語（名詞・用言）と助詞・語尾に分け、
助詞から格を、語尾から時制・文の種類・節のつながりを決めて日本語に訳します。語順（主語-目的語-動詞）も助詞の働きも
日本語に近いので、訳はほぼ語順のままになります。

```
./dragoman.py ko -e "소년이 학교에서 책을 읽었다."
  →  少年が / {学校}〜で,〜から / 本を / 読んだ
  ≒  少年が 学校で 本を 読んだ。  (語順のまま)
./dragoman.py ko -e "나는 어머니가 만든 음식을 먹었다."
  →  私は / 母が作った食べ物を / 食べた
./dragoman.py ko -e "그 사람은 키가 크다."
  →  {その}人は / 背が / 高い
```

ハングルの文は言語を省略しても韓国語と推定します。

「→」の行は共通の解析器が格の枠から組み立てた訳、「≒」の行は語順のままの訳です（`korean/literal.py`）。語節ごとに
内容語の訳に助詞・語尾の日本語の形を当てて、韓国語と同じ順・同じ区切りで並べます。語順も助詞の働きも日本語に近いので、
語節と日本語の文節がほぼ1対1に対応します:

| 韓国語 | 語順のまま |
|---|---|
| 비가 와서 집에 있었다. | 雨が 降って 家に いた。 |
| 나는 어머니가 만든 음식을 먹었다. | 私は 母が 作った 食べ物を 食べた。 |
| 날씨가 좋으면 공원에 가자. | 天気が 良いなら 公園に 行こう。 |
| 그는 밥을 먹으면서 텔레비전을 봤다. | 彼は ご飯を 食べながら テレビを 見た。 |
| 내 친구는 일본에서 왔습니다. | 私の 友達は 日本から 来た。 |

連結語尾は日本語の接続の形に（-고・-어서「〜て」、-지만「〜が」、-(으)면「〜なら」、-(으)면서「〜ながら」、-(으)러「〜しに」、
-어도「〜ても」…）、連体形は連体の形に（만든「作った」）、勧誘は「〜しよう」に。丁寧・尊敬の語尾は訳に出しません（語ごとの表の注に）。

## 助詞と格

| 助詞 | 働き | 訳 |
|---|---|---|
| 이 / 가・께서 | 主格 | が |
| 을 / 를 | 対格 | を |
| 에게・한테・께 | 与格 | に |
| 의 | 属格（後ろの名詞に掛かる） | の |
| 은 / 는 | 主題（格は節の中のほかの名詞句から決める） | は |
| 도・만 | とりたて | も・だけ |
| 에・에서・(으)로・와 / 과・까지・부터・처럼・보다 … | 後置詞句（名詞句の前に移して前置詞句として扱う） | に・で・へ・と・まで・から・のように・より |
| 와 / 과・하고（名詞と名詞の間） | 並列 | と |
| 이 / 가 + 되다・아니다 | 補格 | に（なる）・で（はない） |

* 主題「は」・「も」の名詞と、助詞の無い名詞の格: 이 / 가 の主語が無ければ主格、あれば対格（他動詞で 을 / 를 の句が無いとき）。
  繋辞・形容詞の文で 이 / 가 の主語があれば、主題は格の枠の外の「は」（二重主語: 그 사람은 키가 크다「その人は背が高い」）。
* 名詞の前の助詞の無い名詞は属格（한국 음식「韓国の食べ物」）、助詞の無い時の名詞は副詞（내일「明日」）。

## 語尾と補助用言

* 先語末語尾: 었 → 過去、었었 → 大過去、겠 → 未来・推量、시 → 尊敬（訳には出さず注に）。
* 終結語尾: 命令（-어라・-세요 の一部・-십시오）、勧誘（-자・-ㅂ시다）、丁寧（-습니다・-어요）は注に。
* 連結語尾は節を区切る接続の語にする: -고「そして」、-어서「〜て,〜ので」、-지만「しかし」、-(으)면「〜なら」、
  -(으)니까「〜から」、-는데「〜が」、-면서「〜ながら」…
* 補助用言は本動詞にまとめる: -고 있다「〜ている」、-어 있다「〜ている」（結果）、-어 주다「〜てくれる」、-어 보다「〜てみる」、
  -어 버리다「〜てしまう」、-고 싶다「〜たい」、-어야 하다「〜なければならない」、-게 되다「〜ようになる」、
  -지 않다・안（否定）、-지 못하다・못「〜できない」、-지 말다（禁止）、-(으)ㄹ 수 있다 / 없다「〜できる / できない」、
  -(으)ㄹ 것이다「〜だろう」。
* 連体形（-ㄴ / -은・-는・-ㄹ）は後ろの名詞に掛ける: 補語の無い形容詞は修飾語（예쁜 꽃「{美しい}花」）、ほかは関係節を
  名詞の訳に組み込む（어머니가 만든 음식「母が作った食べ物」）。
* 繋辞 이다（학생입니다「学生である」）・아니다（否定）。形容詞の述語（꽃이 예쁘다）は形容詞 + 見えない繋辞
  （「美しい / 美しかった / 美しくない」）。
* 主語と動詞の決まった組み合わせ: 비가 오다「雨が降る」、눈이 오다「雪が降る」、바람이 불다「風が吹く」…

語ごとの表には、辞書の見出し（漢字語は漢字を添える: 학교 (學校) hakgyo）・助詞・語尾の働き（過去・丁寧・進行 -고 있다 …）を
出します。ローマ字は改訂ローマ字表記の簡略版です（音節末の子音の連音だけ。鼻音化などの音の変化は写さない）。

## 準備

```
pip install kiwipiepy                              # 形態素解析器 (LGPL-3.0。モデルを含む)
mkdir -p ~/.local/share/dragoman-data/ko/ud && cd ~/.local/share/dragoman-data/ko
curl -L -O https://kaikki.org/dictionary/Korean/kaikki.org-dictionary-Korean.jsonl     # 約205MB (CC BY-SA)
cd - && python3 tools/build_korean_dic.py          # → ~/.local/share/dragoman-data/ko/wiktionary.sqlite
```

辞書は Wiktionary の見出し（ハングル。用言は -다 の形）ごとの品詞・英語の語義・漢字・ローマ字です。英語の語義は解析の時に
日本語に直します（`core/en_ja.py`）。基本の語の訳語は `korean/morphology.py` の GLOSSES で決めておきます。

評価用に UD Korean-Kaist（CC BY-SA 4.0）の `ko_kaist-ud-test.conllu` を `~/.local/share/dragoman-data/ko/ud/` に置きます。

## 評価

```
python3 tools/ud_eval.py --lang=ko
```

UD Korean-Kaist のテスト（2,287 文）で、主語の再現率 69%・目的語の再現率 83%、述語の検出 90%。KAIST の注釈は主題の
은 / 는 を主語でなく dislocated とするので、主語の正解は 이 / 가 の主語が中心です。連体形の節は共通の解析器の関係節にする
（節の頭に見えない関係代名詞を補い、先行詞は節の後ろの名詞: `relatives_before_head`）ので、関係節の動詞も述語として数えられます
（名詞の訳に組み込むだけだったときは述語の検出 61%・目的語 81%）。

## まだのこと

* 格の枠の訳（→）でも連結語尾の節を日本語の接続の形に（語順のままの訳では「雨が 降って」、格の枠では「雨が / 降る / 〜て,〜ので」）。
* 出口（`generate/korean.py`）: 한다体の活用、助詞の交替、連体形の関係節、名前はハングルに。比較の表にも。
  入口（`--from=ko`）の関係節はほかの言語でも関係節に（Ich … das Essen, das die Mutter machte）。
