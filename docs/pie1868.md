# 印欧祖語のシュライヒャーの再建（1868）

August Schleicher が1868年に再建した印欧祖語で書いた寓話「羊と馬」（Avis akvāsas ka）を、語ごとに引いて日本語に訳します。
語には今の再建形（喉音のある表記）と、ラテン語・古典ギリシア語・サンスクリットの同源の語を添えます。

これは19世紀の再建の資料で、今の印欧祖語の代表ではありません（下の「1868年版の性格」）。そのため言語の符号は
印欧祖語一般の `ine`・`pie` ではなく `pie1868` にしています。

```
./dragoman.py pie1868 samples/schleicher.txt
./dragoman.py pie1868 --kana samples/schleicher.txt
python3 tools/samples.py --lang=pie1868
```

## 1868年版の性格

当時はサンスクリットが祖語の姿をいちばんよく残すと考えられていて、シュライヒャーの再建はサンスクリット寄り。

* 母音は a・i・u が中心で、e・o を a にまとめる（インド・イラン語派と同じ。今はギリシア語・ラテン語の e/o の方が古いとする）。
* 語形がサンスクリットに近い: akvāsas「馬たち」（ヴェーダ語 áśvāsaḥ）、与格複数 -bhjams（サンスクリット -bhyas。今は
  *-bʰyos と、ゲルマン語・バルト・スラヴ語の -m- 系で説が分かれる）、karnauti「作る」（kṛṇoti）、中動態の -tai（-te）。
* 加音 ā（過去の印）はインド・イラン語派・ギリシア語・アルメニア語などにしか無く、今は祖語の後期の一部の地域のものとする説もある。
* 喉音（*h₁ *h₂ *h₃。ソシュールの推定は1879年、ヒッタイト語での確かめは20世紀）も、アナトリア語派（女性名詞が無いなど）も
  知られる前の再建。羊は avis → 今は *h₂ówis、馬は akvas → *h₁éḱwos。
* 後の書き直し（Lehmann・Zgusta 1979、Kortlandt 2007、Byrd 2013 など）も互いにかなり違う。語根・語彙は確かでも、文に
  すると語尾・語順・小詞で説が分かれ、決まった「印欧祖語の文」は無い。今の版は著作権のある研究なので本文は入れない。

```
Avis akvāsas ka.
  →  羊と馬
Avis akvabhjams ā vavakat:
  →  羊が / 馬に / 言った
Tat kukruvants avis agram ā bhugat.
  →  羊が / {それを 聞いて} / 野を / 逃げた

   0  Avis     (avi) 羊 [Nom.sg.f]
              今の再建: *h₂ówis  同源: ラテン ovis, 古代ギリシア ὄϊς, サンスクリット ávi-
```

## 本文と辞書

* 本文（`samples/schleicher.txt`）は1868年の原文（Beiträge zur vergleichenden Sprachforschung 5, pp. 206–208。パブリックドメイン）。
  後の研究者の書き直し（Lehmann・Zgusta 1979、Byrd 2013 など）は入れない。
* 辞書（`dragoman/pie1868/lexicon.py`）は寓話に出てくる語だけを手で書いたもの。データのダウンロードは要らない。
  * `FORMS`: 本文の語形 → 見出し・品詞・格・数・性（動詞は時制・法・態・人称・数）。格などはシュライヒャーの意図した形（羊 avi- は女性）。
  * `LEMMAS`: 見出し → 訳語・今の再建形・同源の語。今の再建形は見出しの形（名詞は単数主格、動詞は語根）だけで、語形ごとの
    今の形は載せない（akvabhjams の与格複数 -bʰyos / -mos のように、説によって違うところが多い）。

## 表記と読み

* シュライヒャーの表記は19世紀の再建: 喉音（*h₁ *h₂ *h₃）が無い、母音は a・i・u が中心（e・o は a に）、v は今の *w、j は *y、
  k は口蓋音（*ḱ）と唇軟口蓋音（*kʷ）を区別しない（akva = *h₁éḱwos、ka = *-kʷe）。
* 動詞の前に離して書いた ā は加音（過去の印: ā ast「あった」、ā vavakat「言った」、ā bhugat「逃げた」）。動詞に含めて、語の解説に
  「加音 ā 付き」と出す。
* 後置の ka「と」（avis akvāsas ka「羊と馬」）は前の語の手前に移して、ラテン語の et と同じ並列に（パーリ語の ca と同じ）。
* 引用の前の「:」で文を分ける（Avis akvabhjams ā vavakat: / kard aghnutai …）。vividvant-svas はハイフンで2語に分けて引く。
* 1文目の akvams, tam, …, tam, …, tam「馬たちを、一頭は〜、一頭は〜、一頭は〜」: コンマで区切った tam が2つ以上並ぶと
  tam は「一頭」で、分詞（vaghantam「引いている」）は tam に掛け、分詞の前の対格の名詞（vāgham「車を」）は分詞の目的語にする
  （共通の解析器の `distributive_pronouns`）。分詞の無い区切り（tam, bhāram magham「一頭は大きな荷を」）には次の区切りの分詞
  （bharantam「運んでいる」）を括弧付きで補う。語の解説に「省略を補った語」と出る。
* 移動の動詞（bhug「逃げる」）の対格は方向の「へ」（agram ā bhugat「野へ逃げた」）。
* 関係代名詞 jasmin（処格「その上に」）は、辞書の空所の訳（`gap_ja`）を関係節の頭に出す（{その上に 羊毛が なかった}羊）。
* 存在の ast（jasmin varnā na ā ast「その上に羊毛の無かった」）は繋辞にしない（「羊毛ではなかった」にならないように）。
* カタカナ（`pie1868/katakana.py`）は綴りから: 長母音は「ー」、v は「ヴ」、j はヤ行、有気音 bh・dh・gh は b・d・g と同じ
  （avis → アヴィス、bhāram → バーラム、jasmin → ヤスミン）。
