# 中国語（普通話。作りかけ）

中国語の文を語に切り分け、spaCy の中国語モデル（zh_core_web_sm）で品詞（OntoNotes のタグ）と依存関係を付けてから、
中国語の構文（量詞・的・アスペクト・把・被・方位詞）をまとめ、共通の解析器（格の枠）で日本語に訳します。簡体字も繁体字も
読みます（繁体字は OpenCC で簡体字に直して解析し、表示は元の字のまま）。訳語は CC-CEDICT の英語の語義を日本語に直したもの
（基本の語は morphology.GLOSSES で決めておく）。

```
./dragoman.py zh -e "我昨天买了一本书。"
  我昨天买了一本书。  (wǒ zuótiān mǎi le yī běn shū.)
  →  昨日 / 私が / 一冊の本を / 買った
./dragoman.py zh -e "我没去过中国。"         →  私が / 中国に / 行ったことがない
./dragoman.py zh -e "我买的书很有意思。"     →  私が買う本は / とても面白い
./dragoman.py zh -k -e "月亮代表我的心。"    カナ: ユエリャン ダイビャオ ウォ ダ シン
python3 tools/samples.py --lang=zh          # サンプル (samples/chinese.txt) の訳
```

かなの無い漢字の文は中国語と推定します（かなのある文は古文）。

## 扱うもの

* 語の切り分け（`chinese/segment.py`）: spaCy の pkuseg の切り分けを基本に、辞書に無い語（书放）は CC-CEDICT の見出しの
  最長一致（前から・後ろから。語の数・1字の語の少ないほう）で分け直し、数詞・指示詞の後ろの「量詞 + 名詞」（本书）は量詞の前で切る
* 格: 依存関係から（主語・目的語・介詞の目的語）。名詞 + 名詞の複合語は前の名詞が後ろに掛かる（主体大修工程「本体の
  リニューアルの 工事」）。移動の動詞（去・来・回・到）の目的語は行き先「〜に」
* 数詞・指示詞 + 量詞は名詞に掛かる形容詞（一本书「一冊の本」、这个问题「この問題」）。量詞は日本語の助数詞に（本 → 冊、张 → 枚）
* 的: 名詞 + 的 + 名詞は属格（妈妈的书「母の本」）、代名詞 + 的は所有「私の」、動詞の句 + 的 + 名詞は連体修飾節
  （我买的书「私が買う本」）
* アスペクト: 了「〜した」、过「〜したことがある」、着・在 / 正在 + 動詞「〜している」。没 / 没有 + 動詞は「〜しなかった」
  （没 + 动词 + 过 は「〜したことがない」）、不は現在の否定
* 把構文（処置文）: 把 + 名詞は目的語「〜を」で、訳でも目的語を先に（他把书放在桌子上「彼が / 本を / 机の上に / 置く」）。
  解析の表の動詞に「把構文 (把 + 目的語 + 動詞: 目的語を どうするか (処置))」、名詞に「把 の目的語」の注
* 被（+ 動作主）は受動「〜によって 〜された」
* 補語を動詞にまとめる: 結果・方向の補語（看完「読み終える」、听懂「聞いて分かる」、走进来「歩いて入って来る」、
  決まった組: 站起来「立ち上がる」・想起来「思い出す」）、可能の補語（听得懂「聞いて分かることができる」、看不懂「読んで分かることが
  できない」）、様態の補語（跑得很快「とても速く走る」）
* 主語の後ろの也・都は主語に（我也去「私も」、我们都是学生「私たちはみな」）。人を数える个は「人」（两个朋友「二人の友人」）
* 介詞（在・从・到・给 …）と方位詞（桌子上「机の上」）。動詞の後ろの在・到・给は「〜に」（放在桌子上「机の上に 置く」）、
  存在の在（书在桌子上）は「〜にある」
* 所有・存在の有: 前の人は「〜には」、場所は「〜に」、有るものは「〜が」（我有两个朋友「私には / 二人の友人が / いる」、
  桌子上有一本书「机の上に / 一冊の本が / ある」）。没有 + 名詞は「ない」（我没有钱「私には / {硬貨,金銭}が / ない」）。
  節の終わりの有人は 有 / 人（这里有人吗「ここに / 人が / いるか」）、文頭の有人は「ある人」。很多 + 名詞は「たくさんの」
* 補文: 「言う・思う」の動詞（说・觉得・认为・希望 …）の後ろの主語のある節は「{…}と」「{…}ことを」
  （我觉得他会来「私が / {彼が 来るだろう}と / 思う,感じる」）。補文の会は見込み「〜だろう」。说 + 言葉は「話す」
* 形容詞の述語（问题很难「問題は とても難しい」）は形容詞 + 見えない繋辞。很・非常 … は形容詞に付ける
* 助動詞（会・能・想・要・应该 …）+ 動詞は1語に（想去「行きたい」）
* 副詞節（因为・如果・虽然 …）、間接疑問（知道 + 哪儿 …。補文の主語は後ろの節に）、疑問の吗（文末の？を補う）。吧・呢・啊は訳さない

## カタカナ（`chinese/katakana.py`）

語の拼音（pypinyin。熟語の読みとよく使う読み）の音節ごとに、声母の行と韻母の段で。声調と長さは書かない。

* 無気音 b・d・g・j・zh・z はバ・ダ・ガ・ジャ・ジャ・ザ行、有気音 p・t・k・q・ch・c はパ・タ・カ・チャ・チャ・ツァ行
  （日本語の耳には無気音が濁って聞こえる）。x・sh はシャ行、r はラ行
* 省いて書く韻母は元の形で: iu = iou「ヨウ」（九 → ジョウ）、ui = uei「ウェイ」（对 → ドゥェイ）、un = uen（文 → ウェン、
  子音の後ろは「ウン」: 春 → チュン）
* j・q・x・y の後ろの u は ü（去 → チュ、学 → シュエ、月 → ユエ）。zi・ci・si → ズ・ツ・ス、zhi・chi・shi・ri → ジ・チ・シ・リ
* e は「ウ」（喝 → フ）、軽声の e は「ア」（的 → ダ、了 → ラ）。eng・ong は「オン」、儿化の r は「ル」（哪儿 → ナル）

ルビの口（`--kana-json`）は語に切り分けた区切りごとに。

## 評価（`tools/ud_eval.py --lang=zh`）

UD Chinese-GSDSimp（CC BY-SA 4.0。`$DRAGOMAN_DATA/zh/ud/`）の test 500 文で（2026-10-27）。語の切れ目は UD のまま渡す。

| 項目 | |
|---|---|
| 形容詞→名詞 | 再現率 51.5%・適合率 35.2% |
| 属格→名詞 | 再現率 53.3%・適合率 67.1% |
| 述語の検出 | 72.0% |
| 主語 | 39.8% |
| 目的語 | 44.6% |

有 + 名詞は訳で「〜がある」の主語なので主語として測る。低い数字の多くは百科事典の文の形による: 名詞の述語
（总面积11.61平方公里）、UD が接尾辞を別の語にする切り方（博物 / 馆、供应 / 商、位 / 于）、読点で並べた動詞句。

## まだできないこと

* 数量を述語の後ろに回す訳（「私には 友人が 二人 いる」）はしない（「二人の友人が」のまま）
* 声調の変化（一・不 の変調、3声の連続）はカナに関係しないので扱わない。見出しの拼音は辞書の声調のまま
* 文の生成（generate/）はまだ
