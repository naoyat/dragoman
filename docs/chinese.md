# 中国語（普通話。作りかけ）

中国語の文を語に切り分け、spaCy の中国語モデル（zh_core_web_sm）で品詞（OntoNotes のタグ）と依存関係を付けてから、
中国語の構文（量詞・的・アスペクト・把・被・方位詞）をまとめ、共通の解析器（格の枠）で日本語に訳します。簡体字も繁体字も
読みます（繁体字は OpenCC で簡体字に直して解析し、表示は元の字のまま）。訳語は CC-CEDICT の英語の語義を日本語に直したもの
（基本の語は morphology.GLOSSES で決めておく）。

```
./dragoman.py zh -e "我昨天买了一本书。"
  我昨天买了一本书。  (wǒ zuótiān mǎi le yī běn shū.)
  →  昨日 / 私が / 一冊の本を / 買った
./dragoman.py zh -e "我没去过中国。"         →  私が / 中国に / 行ったことがない
./dragoman.py zh -e "我买的书很有意思。"     →  私が買う本は / とても面白い
./dragoman.py zh -k -e "月亮代表我的心。"    カナ: ユエリャン ダイビャオ ウォ ダ シン
python3 tools/samples.py --lang=zh          # サンプル (samples/chinese.txt) の訳
```

かなの無い漢字の文は中国語と推定します（かなのある文は古文）。

## 扱うもの

* 語の切り分け（`chinese/segment.py`）: spaCy の pkuseg の切り分けを基本に、辞書に無い語（书放）は CC-CEDICT の見出しの
  最長一致（前から・後ろから。語の数・1字の語の少ないほう）で分け直し、数詞・指示詞の後ろの「量詞 + 名詞」（本书）は量詞の前で切る
* 格: 依存関係から（主語・目的語・介詞の目的語）。名詞 + 名詞の複合語は前の名詞が後ろに掛かる（主体大修工程「本体の
  リニューアルの 工事」）。移動の動詞（去・来・回・到）の目的語は行き先「〜に」
* 数詞・指示詞 + 量詞は名詞に掛かる形容詞（一本书「一冊の本」、这个问题「この問題」）。量詞は日本語の助数詞に（本 → 冊、张 → 枚）
* 的: 名詞 + 的 + 名詞は属格（妈妈的书「母の本」）、代名詞 + 的は所有「私の」、動詞の句 + 的 + 名詞は連体修飾節
  （我买的书「私が買う本」）
* アスペクト: 了「〜した」、过「〜したことがある」、着・在 / 正在 + 動詞「〜している」。没 / 没有 + 動詞は「〜しなかった」
  （没 + 动词 + 过 は「〜したことがない」）、不は現在の否定
* 把構文（処置文）: 把 + 名詞は目的語「〜を」で、訳でも目的語を先に（他把书放在桌子上「彼が / 本を / 机の上に / 置く」）。
  解析の表の動詞に「把構文 (把 + 目的語 + 動詞: 目的語を どうするか (処置))」、名詞に「把 の目的語」の注
* 被（+ 動作主）は受動「〜によって 〜された」
* 補語を動詞にまとめる: 結果・方向の補語（看完「読み終える」、听懂「聞いて分かる」、走进来「歩いて入って来る」、
  決まった組: 站起来「立ち上がる」・想起来「思い出す」）、可能の補語（听得懂「聞いて分かることができる」、看不懂「読んで分かることが
  できない」）、様態の補語（跑得很快「とても速く走る」）
* 主語の後ろの也・都は主語に（我也去「私も」、我们都是学生「私たちはみな」）。人を数える个は「人」（两个朋友「二人の友人」）
* 介詞（在・从・到・给 …）と方位詞（桌子上「机の上」）。動詞の後ろの在・到・给は「〜に」（放在桌子上「机の上に 置く」）、
  存在の在（书在桌子上）は「〜にある」
* 所有・存在の有: 前の人は「〜には」、場所は「〜に」、有るものは「〜が」（我有两个朋友「私には / 二人の友人が / いる」、
  桌子上有一本书「机の上に / 一冊の本が / ある」）。没有 + 名詞は「ない」（我没有钱「私には / {硬貨,金銭}が / ない」）。
  節の終わりの有人は 有 / 人（这里有人吗「ここに / 人が / いるか」）、文頭の有人は「ある人」。很多 + 名詞は「たくさんの」
* 補文: 「言う・思う」の動詞（说・觉得・认为・希望 …）の後ろの主語のある節は「{…}と」「{…}ことを」
  （我觉得他会来「私が / {彼が 来るだろう}と / 思う,感じる」）。補文の会は見込み「〜だろう」。说 + 言葉は「話す」
* 形容詞の述語（问题很难「問題は とても難しい」）は形容詞 + 見えない繋辞。很・非常 … は形容詞に付ける
* 助動詞（会・能・想・要・应该 …）+ 動詞は1語に（想去「行きたい」）
* 副詞節（因为・如果・虽然 …）、間接疑問（知道 + 哪儿 …。補文の主語は後ろの節に）、疑問の吗（文末の？を補う）。吧・呢・啊は訳さない

## カタカナ（`chinese/katakana.py`）

語の拼音（pypinyin。熟語の読みとよく使う読み）の音節ごとに、声母の行と韻母の段で。声調と長さは書かない。

* 無気音 b・d・g・j・zh・z はバ・ダ・ガ・ジャ・ジャ・ザ行、有気音 p・t・k・q・ch・c はパ・タ・カ・チャ・チャ・ツァ行
  （日本語の耳には無気音が濁って聞こえる）。x・sh はシャ行、r はラ行
* 省いて書く韻母は元の形で: iu = iou「ヨウ」（九 → ジョウ）、ui = uei「ウェイ」（对 → ドゥェイ）、un = uen（文 → ウェン、
  子音の後ろは「ウン」: 春 → チュン）
* j・q・x・y の後ろの u は ü（去 → チュ、学 → シュエ、月 → ユエ）。zi・ci・si → ズ・ツ・ス、zhi・chi・shi・ri → ジ・チ・シ・リ
* e は「ウ」（喝 → フ）、軽声の e は「ア」（的 → ダ、了 → ラ）。eng・ong は「オン」、儿化の r は「ル」（哪儿 → ナル）

ルビの口（`--kana-json`）は語に切り分けた区切りごとに。

## 文の生成 (出口)

ほかの言語の文の枠から中国語（簡体字）の文を作ります（`generate/chinese.py`）。比較の表（`tools/generate.py --compare`）にも
出ます。中国語の文からも作れます（`--from=zh`。下の「入口」）。

```
python3 tools/generate.py --to=zh "Puella rosam pulchram in hortō videt."
  中国語:   女孩在花园里看见美丽的玫瑰。
python3 tools/generate.py --to=zh "Mihi est liber. Puer ā magistrō laudātus est. Rēge mortuō populus flēvit."
  中国語:   我有一本书。  /  男孩被老师称赞了。  /  国王死了以后，人群哭了。
```

* 語は英語を仲立ちにした置き換え（`transfer.py`）。英語の索引 `zh/en-index.tsv` は CC-CEDICT から
  （`tools/build_english_index.py --lang=zh`。品詞は CC-CEDICT に無いので見当: 語義が "to …" なら動詞、英語の訳語が形容詞に
  なれば形容詞（`tools/build_chinese_dic.py`））。UD の出現数（`tools/build_lemma_counts.py --lang=zh`）と、教科書の基本の語
  （transfer.PREFERRED: 国王 を 辟 より、农夫 を 庄稼汉 より）で選ぶ。名前の漢字の表は無いので、ほかの言語の固有名詞は
  ラテン文字のまま（長音符は除く）。
* 名詞句: 指示詞・数詞 + 量詞（这个女孩・两个男孩。量詞は CC-CEDICT の CL:、無ければ个）+ 形容詞 + 名詞。1字の形容詞は的なし
  （好人）、2字以上は的（美丽的玫瑰）、並列は 又A又B的。属格は 〜的、関係節・名詞に掛かる分詞は 節 + 的（老师称赞的男孩・
  逃跑的敌人）。
* 語順: 主語 - 時の副詞 - 否定 - 介詞句（在花园里・从…・和朋友一起・用…・给 + 受け手）- 動詞 - 目的語。行き先は動詞の後ろ
  （走到城镇、去・回 はそのまま）。方位詞は 里（面の名詞は 上: 在路上）。给・送・告诉・教 は受け手を目的語の前に
  （给了女孩玫瑰）。
* 時制: 完了は 動詞 + 了、過去完了 已经、未来 会、否定は 不（完了は 没 で 了 を付けない）、受動 被（+ 動作主）。
* 繋辞: 名詞は 是、形容詞は 很 + 形容詞（並列は 长又宽）、場所は 在、存在の文と所有の与格は 有 + 一 + 量詞 + 名詞（我有一本书）。
  疑問文は文末に 吗（疑問詞があれば付けない）と ？。疑問詞はその場に（他什么时候来・女孩在哪里・男孩看见谁。
  疑問の副詞は主語の後ろ）。
* 補文・知覚の不定詞は節のまま（我知道你来・我看见女孩唱歌）、話法の動詞は 能・想・应该 + 動詞。独立奪格は 〜的时候（現在）・
  〜了以后（過去）、述語的な分詞は 動詞 + 着（摘着花）、過去の受動の分詞は 被 + 動詞。

## 文の生成 (入口: `--from=zh`)

中国語の文を解析して文の枠にし、ほかの言語の文を作ります。元の中国語に戻した文が入力と同じ字になれば ✓（語の切れ目は書かないので
字で比べる）。

```
python3 tools/generate.py --from=zh "女孩在花园里看见美丽的玫瑰。"
  ラテン語: Puella rosam pulchram in hortō videt.
  英語:     The girl sees the beautiful rose in the garden.
  ポルトガル語: A menina vê a rosa bonita no jardim.
python3 tools/generate.py --from=zh "我有一本书。" "李明住在北京。"
  日本語:   私には本がある。  /  李明は北京に住む。
  英語:     I have a book.  /  Li Ming lives in Beijing.
```

* 解析で名詞の訳に組み込んだもの（連体修飾の形容詞 美丽的、方位詞 里・上・下面）は枠では元の形に: 形容詞は修飾語、方位詞は
  前置詞（在…里・上 → in、在…下 → sub、在…前 → ante）。元の介詞と方位詞も持つ（中国語に戻すとき 在花园里）。
* 一 + 量詞（一本书）・数詞 + 量詞は不定の名詞（ほかの言語では a book。ūnus にしない）、这・那 は定。
* 有 + 名詞は繋辞 + 主語（我有 → 所有の与格 mihi est、桌子上有 → 場所）。是 も繋辞。二重目的語（给女孩一本书）の前の方は受け手、
  結果の補語 到（跑到家里）は行き先、助動詞（会说・想去・应该）は話法の動詞 + 不定詞、補文の 会（我觉得他会来）は未来。
* 動詞は人称で変わらないので、人称は主語の代名詞から。她 は女性、名詞 + 们 は人の複数（中国語に戻すとき 士兵们）。代名詞 + 名詞
  （我爸爸）は所有。
* 固有名詞はラテン文字の綴りに（CC-CEDICT の英語の名前: 北京 → Beijing、辞書に無い人名は拼音: 李明 → Li Ming）、日本語は漢字の
  まま。辞書に無い人名は姓 + 1〜2字で切り出す（pkuseg は 李明住 を1語にする）。
* 英語の訳語は教科書の基本の語の表（transfer.PREFERRED）を逆に引いて決める（玫瑰 → rose。CC-CEDICT の最初の語義は
  rugosa rose）。CC-CEDICT の語義の後ろの空所（to think that ...）は除く。
* 存在の動詞の 在（女孩在花园里）は場所の繋辞（sum + in）。疑問詞: 什么时候（pkuseg の 什么 / 时候 を1語に）・为什么・怎么は
  疑問の副詞、哪里・哪儿 は介詞で ubi / unde（从哪里）/ quō（去哪里）、谁・什么 は疑問代名詞。

## 評価（`tools/ud_eval.py --lang=zh`）

UD Chinese-GSDSimp（CC BY-SA 4.0。`$DRAGOMAN_DATA/zh/ud/`）の test 500 文で（2026-10-27）。語の切れ目は UD のまま渡す。

| 項目 | |
|---|---|
| 形容詞→名詞 | 再現率 51.5%・適合率 35.2% |
| 属格→名詞 | 再現率 53.3%・適合率 67.1% |
| 述語の検出 | 72.0% |
| 主語 | 39.8% |
| 目的語 | 44.6% |

有 + 名詞は訳で「〜がある」の主語なので主語として測る。低い数字の多くは百科事典の文の形による: 名詞の述語
（总面积11.61平方公里）、UD が接尾辞を別の語にする切り方（博物 / 馆、供应 / 商、位 / 于）、読点で並べた動詞句。

## まだできないこと

* 数量を述語の後ろに回す訳（「私には 友人が 二人 いる」）はしない（「二人の友人が」のまま）
* 声調の変化（一・不 の変調、3声の連続）はカナに関係しないので扱わない。見出しの拼音は辞書の声調のまま
* 入口（`--from=zh`）: 形容詞1語でない連体修飾節（我买的书）は文の枠に入らない（名詞の訳の中だけ）
